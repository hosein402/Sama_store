# SAMA Store — راه‌اندازی

این نسخه بدون سیستم گزارش‌گیری است. فروشگاه شامل صفحه فروشگاه، محصول، سبد، ثبت‌نام/ورود، آدرس، ثبت سفارش و پنل مدیریت محصولات و سفارش‌هاست.

## قبل از انتشار
1. Node.js 20+ نصب باشد.
2. PostgreSQL بسازید و `DATABASE_URL` را تنظیم کنید.
3. یک `AUTH_SECRET` تصادفی و طولانی تنظیم کنید.
4. `npm install`
5. `npm run db:generate`
6. `npm run db:push`
7. `npm run db:seed`
8. `npm run build`
9. `npm start`

## درگاه پرداخت
در این نسخه درگاه آنلاین هنوز پیاده‌سازی نشده است. سفارش با وضعیت `PENDING` ثبت می‌شود و مدیر پس از تأیید پرداخت آن را `PAID` می‌کند. در این لحظه فروش محصول در `sold` ثبت می‌شود.

## ساخت مدیر
برای امنیت، کاربر مدیر را مستقیماً در دیتابیس با `role = ADMIN` تعیین کنید؛ رمز عبور باید با تابع `hashPassword` پروژه هش شود.

## نکته موجودی
هنگام ثبت سفارش، موجودی رزرو/کسر می‌شود. با لغو سفارش، موجودی آزاد می‌شود. تا قبل از `PAID` مقدار `sold` افزایش پیدا نمی‌کند.
